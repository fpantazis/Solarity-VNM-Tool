# Solarity-VNM-Tool 3.x
VNM Tool  for Solarity Renewable Energy Community

Η εφαρμογή διαβάζει αυτόματα από τον ιστότοπο της ΔΕΗ τους λογαριασμούς και παράγει αναλυτικές αναφορές σε Excel, με βάση τις επίσημες τιμές της ΔΕΗ για κάθε μήνα και κάθε
  πρόγραμμα.
  Απευθύνεται σε κάθε οικιακό πελάτη της ΔΕΗ, όχι μόνο σε μέλη ενεργειακών κοινοτήτων:

  - Έλεγχος Συμψηφισμού (VNM) — για μέλη ενεργειακών κοινοτήτων: επαλήθευση του εικονικού ενεργειακού συμψηφισμού,
    έλεγχος ορθότητας των λογαριασμών και παρακολούθηση της απόσβεσης της επένδυσης.
  - Σύγκριση Προγραμμάτων ΔΕΗ — για οποιονδήποτε πελάτη, χωρίς καμία σχέση με συμψηφισμό: σύγκριση των σταθερών και
    κυμαινόμενων οικιακών προγραμμάτων πάνω στη δική σας πραγματική κατανάλωση, ώστε να δείτε τι θα πληρώνατε σε κάθε
    ένα.
  - Δυναμικά Προγράμματα — ανάλυση δυναμικού τιμολογίου με τις ωριαίες τιμές της Προ-Ημερήσιας Αγοράς, για να
    διαπιστώσετε αν το δυναμικό τιμολόγιο συμφέρει στο δικό σας προφίλ κατανάλωσης.

  Προαιρετικά, με χρήση API κλειδιού απο το ΔΕΔΔΗΕ, η ανάλυση αξιοποιεί τα πραγματικά δεδομένα του έξυπνου μετρητή σας ανά 15 λεπτά,
  για τη μέγιστη δυνατή ακρίβεια.
